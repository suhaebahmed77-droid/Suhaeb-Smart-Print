How to Connect Your Printer

Works with Android Wi-Fi Print Service, Epson Smart Panel, or PC Auto-Print Bridge

Best for Android Counter Phone: Print directly to any Wi-Fi printer (Epson L3250, HP Smart Tank, Canon Pixma) from Chrome without a PC.
  1. 1

    Connect Phone & Printer to the Same Wi-Fi

    Join your printer and Android phone to the same Wi-Fi router (or enable Wi-Fi Direct on the printer and connect your phone to its Wi-Fi network).

  2. 2

    Enable Print Service / Epson Smart Panel

    Install Epson Print Enabler / Epson Smart Panel (or Mopria Print Service for HP/Canon/Brother) from Play Store. Then open Android Settings → Connected devices → Printing and turn the service ON.

  3. 3

    Print Directly from the Queue

    In Admin Dashboard, tap Preview & Print → Print Document, pick your Wi-Fi printer in the Android print dialog, confirm copies & colour, and tap Print.

Option A — Chrome Silent Kiosk Printing (Zero-Click Default Printer):

Close all Chrome windows, then start Chrome with --kiosk-printing and turn ON Browser Print Dialog in Admin Automation Controls.

Option B — Local Python Bridge Webhook (For All 4 Slots)

Run pip install flask flask-cors pywin32 (Windows), save as bridge.py, run python bridge.py, and paste http://localhost:5050/print into any Printer Slot's Bridge URL field. 

from flask import Flask, request, jsonify
from flask_cors import CORS
import base64, os, tempfile, platform, subprocess

app = Flask(__name__)
CORS(app)

@app.route("/print", methods=["POST"])
def print_job():
    data = request.get_json(force=True)
    job_id = data.get("jobId", "JOB")
    slot_name = data.get("slotName", "")
    file_data = data.get("fileData")
    copies = int(data.get("copies", 1))
    color_mode = data.get("colorMode", "bw")

    if not file_data:
        return jsonify({"ok": False, "error": "No fileData"}), 400

    header, b64 = file_data.split(",", 1) if "," in file_data else ("", file_data)
    ext = ".pdf" if "pdf" in header.lower() else ".jpg"
    tmp_path = os.path.join(tempfile.gettempdir(), f"{job_id}{ext}")
    with open(tmp_path, "wb") as f:
        f.write(base64.b64decode(b64))

    try:
        for _ in range(max(1, copies)):
            if platform.system() == "Windows":
                import win32api
                win32api.ShellExecute(0, "print", tmp_path, None, ".", 0)
            else:
                cmd = ["lp"]
                if color_mode == "bw":
                    cmd += ["-o", "ColorModel=Gray"]
                cmd.append(tmp_path)
                subprocess.run(cmd, check=True)
        return jsonify({"ok": True, "jobId": job_id, "slot": slot_name})
    except Exception as e:
        return jsonify({"ok": False, "error": str(e)}), 500

if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5050)
